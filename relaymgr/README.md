# 内网管家（relaymgr）

跑在飞牛 fnOS 上的原生 FPK 应用，把「方案 D · 公网直连」落地成可安装的程序：路由器上映射一条公网端口到 NAS，应用里再建一条转发规则指到内网主机，外网就能直接连上内网主机的远程桌面、SSH、VNC 或 Web 管理页。不需要中继，也不需要在内网主机装任何客户端。

- 应用名：内网管家（appname `relaymgr`）
- 版本：1.2.4 · 架构 x86
- 服务端口：8899（安装向导里可改成任意 1024-65535 端口）
- 运行方式：单静态二进制，不依赖 Docker，不依赖 Node/PHP 运行时

## 功能

**端口转发**：TCP/UDP 任意端口转发，规则可增删改、保存即生效不用重启；实时显示活动连接与收发字节；监听失败会自动回滚，不会留下占着端口却起不来的坏规则。

**端口扫描**：按单 IP、地址区间（`192.168.1.10-60`）或网段（`/24`、`/16`）探测开放端口，识别 Web 面板、NAS、远程桌面与风险端口，标注本机 / 网关 / 新设备，支持全端口 1-65535、表格与树形图两种显示、结果导出 CSV。

**本机端口**：列出 NAS 上的监听端口，自动区分 Docker 容器、飞牛应用与系统进程，看到想对外开放的点一下就能生成转发规则。

**双栈与安全**：管理界面与转发端口同时支持 IPv4/IPv6；口令登录（PBKDF2-SHA256 12 万轮），失败锁定时间递增，全站限速，会话 12 小时，来源 IP 白名单，操作全程审计。

**皮肤**：青（默认）/ 石墨 / 深色三套，设置页一键切换。

## 安装

1. 飞牛桌面 → 应用中心 → 右上角「…」→ 安装本地应用，选择本目录下的 `relaymgr-1.2.4-x86_64.fpk`
2. 向导页填写管理端口（默认 8899）与是否启用 IPv6
3. 装完桌面出现「内网管家」图标，点开首次使用直接设置管理口令（公网打开也可以初始化，设置完成后初始化入口永久关闭）

## 三步打通远程桌面

1. 路由器把公网端口（例如 13389）映射到 NAS 的 13389
2. 应用里建规则：监听 13389 → 目标 `192.168.1.50:3389`
3. 外网用远程桌面客户端连 `公网IP:13389`

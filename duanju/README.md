装在飞牛 NAS 上的一站式短剧看剧神器，一个应用聚合全网短剧资源，首页即看、剧场分类、排行搜索全都有。

## 核心功能

- **多源聚合**：内置七猫、西饭、星芽、牛牛 4 个稳定短剧源，默认全部启用，开箱即看
- **可扩展**：设置页支持一键添加接口文件（.js），河马、嘟嘟、短剧粉、短剧聚合、网盘类玩偶等接口通吃，片源自己说了算
- **三个主界面**：首页（热门推荐）、剧场（分类浏览 + 排行）、设置（源管理 + 皮肤）
- **齐全的观看体验**：短剧分类、搜索、详情、选集、断点续播，播放器支持 HLS 直链
- **手机友好**：触屏优化、横屏全屏播放、底部安全区适配，手机 / 平板 / 电视浏览器都能看
- **好看又听话**：7 种主题皮肤随意切换（红 / 橙 / 绿 / 蓝 / 紫 / 粉 / 金），记忆你的选择

## 技术特点

- 飞牛原生应用（.fpk 一键安装），也支持 Docker 部署
- 端口 3009，IPv4/IPv6 双栈访问
- 智能缓存加速：首页秒开、多源并行抓取
- 自动清理失效接口文件，接口坏了不用手动删

**安装方式**：飞牛应用中心 → 手动安装 → 上传 fpk 包，30 秒装好，浏览器打开即用。
